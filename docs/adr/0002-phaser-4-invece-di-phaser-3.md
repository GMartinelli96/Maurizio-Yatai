# Phaser 4 invece di Phaser 3.90

Gli altri giochi di Maurizio usano Phaser 3.90, ma Maurizio Yatai usa Phaser 4 (4.2): le skill di sviluppo che usiamo per costruirlo sono scritte per Phaser 4, e il gioco è autonomo, quindi non condivide codice con la suite (vedi [ADR-0001](./0001-gioco-autonomo-senza-file-di-grafica-e-audio.md)).

## Consequences

Chi mantiene la suite troverà API in parte diverse da quelle che conosce. Le differenze principali con Phaser 3 vanno elencate nel LEGGIMI del regalo.
